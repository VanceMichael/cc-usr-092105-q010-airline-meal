# 领域约定

## 核心对象

- 航段
- 舱位
- 餐食选择
- 配餐截止时间
- 供应批次
- 食品安全资格
- 装机清单
- 实际发放
- 履约记录
- 旅客权益

## 履约链路

履约记录是一份餐从选择到发放的唯一主线，必须串联：航段、舱位、旅客选择、配餐截止时间、供应批次、食品安全资格、装机清单、实际发放。客服对一份餐"被装载、替换、取消或转为里程、餐券"的任何解释，都必须能回溯到这条记录，不允许存在记录之外的结论。

## 已知规则

- 弃餐权益只能在确认未装餐后到账，奖励与实际装载结果必须一致
- 付费升级餐与免费保障餐采用同一食品安全底线，特殊餐安全标准不得降低
- 改签后旧航段的选择要明确失效；配餐截止后发生换机型或改签时，不得出现旧机场已装餐、新机场又按原选择重复生产的双份有效结果
- 关舱前乘务组只能拿到唯一有效的餐食名单
- 多人同时改选、联程拆分、供应商缺货、重复航班消息、积分补偿重放、延误餐券部分使用，都不得产生第二份有效结果（同一业务动作只结算一次）

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
