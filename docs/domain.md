# 领域约定

## 核心对象

- 航段：承运的一段航班，换机型或改签会产生新旧航段
- 舱位：旅客在航段上的舱等，决定可供选择的餐食范围
- 餐食选择：旅客对某航段的选择，含弃餐换里程、付费餐食与免费特殊餐
- 配餐截止时间：航段停止接受改选、锁定生产数量的时间点
- 供应批次：供应商某次生产的餐食批次
- 食品安全资格：供应商与供应批次必须满足的航空保障与统一安全标准
- 装机清单：某航段某次装机的餐食明细
- 实际发放：乘务组在机上实际发放的记录
- 履约记录：串联以上对象的唯一有效履约凭证
- 旅客权益：里程、餐券等补偿与兑换结果

## 履约记录

履约记录把航段、舱位、餐食选择、配餐截止时间、供应批次、食品安全资格、装机清单和实际发放串成一条可追查的链路：

- 关舱前乘务组只能拿到一份唯一有效的餐食名单
- 客服依据履约记录解释每份餐为何被装载、替换、取消或转为里程、餐券

## 已知规则

- 弃餐奖励与实际装载结果必须一致：弃餐权益只能在确认未装餐后到账
- 特殊餐安全标准不得降低：付费升级餐与免费保障餐适用同一食品安全底线
- 改签后旧航段的选择要明确失效：配餐截止后换机型或改签时，已确认装餐的旧航段不得在新机场按原选择重复生产
- 多人同时改选、联程拆分、供应商缺货、重复航班消息、积分补偿重放、延误餐券部分使用均不得产生第二份有效结果

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
